# almonadavid.github.io

Personal website for David Almona, built with [Quarto](https://quarto.org/) and hosted on GitHub Pages.

## Structure

- `index.qmd` — Home/landing page
- `about.qmd` — Education, experience, and conferences
- `projects.qmd` — Portfolio of data and analytics projects
- `assets/` — Images, PDFs (résumé, project files)
- `projects/` — Project reports, slides, and posters
- `_quarto.yml` — Site configuration
- `styles.css` — Custom styles

## Local Development

Requires [Quarto](https://quarto.org/docs/get-started/).

```bash
quarto preview
```

To build the site:

```bash
quarto render
```
